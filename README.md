# Java Practice Workspace

This workspace contains Java practice exercises grouped by week.

## Structure

- `Week-1/` - beginner problem-solving exercises
- `Week-2/` - strings, validation, formatting, and CSV exercises
- `Week-3/` - basic Java classes, control flow, and small programs
- `Week-4/` - array and algorithm practice
- `Week-5/` - sorting, collections, and object-oriented exercises
- `Week-6/` - object-oriented programming fundamentals

Each week is kept as an independent default-package exercise set. Compile one week at a time with the VS Code task menu so duplicate class names in different weeks do not conflict.

## Running an exercise

1. Open the Command Palette with `Ctrl+Shift+P`.
2. Select `Tasks: Run Task`.
3. Choose the compile task for the required week, including Week 5 or Week 6.
4. Use the Java extension's Run button inside the file, or run a compiled class from the matching `.build/Week-*` folder in the terminal.

Compiled files are written to `.build/` and are ignored by Git.
